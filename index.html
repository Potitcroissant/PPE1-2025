Le mini-projet

Le mini-projet sert d'introduction au projet final. Il nous permet de nous familiariser avec les outils que l'on utilisera dans le projet final.

Il a été séparé en trois parties:

  1. Création du tableau récapitulatif des URLs, ajout d'informations complémentaires.
  2. Introduction au langage HTML, création d'une page HTML pour le tableau précédemment créé.
  3. Introduction au langage CSS et aux pages git. Création d'une page git combinant HTML et CSS ainsi que Bulma.
